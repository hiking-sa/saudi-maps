# saudi-maps

خرائط المناطق (بدون نت) لتطبيقَي «نادي التحدي والصمود» و«هايكنج السعودية».

- المصدر: بيانات OpenStreetMap (© مساهمو OpenStreetMap، رخصة ODbL) وبيانات الارتفاع.
- يتجهّز هنا تلقائيًا ملف لكل منطقة، ويُرفع لمخزن التطبيق.

## كيف تشتغل
- حدود المناطق الـ ١٣ تُستخرج من بيانات OpenStreetMap (Geofabrik).
- الخريطة نفسها تُقص لكل منطقة من أحدث نسخة يومية لخريطة العالم المبنية من OpenStreetMap (Protomaps).
- تُرفع الملفات على مخزن Cloudflare R2 باسم `regions/<المنطقة>.pmtiles` ومعها `index.json`.
- التشغيل تلقائي كل شهر، ويقدر يتشغل يدويًا من تبويب Actions.
